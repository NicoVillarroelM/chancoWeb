```
# Municipalidad de Chanco - Rediseño Web

Este proyecto es una propuesta de rediseño de la página web de la Municipalidad de Chanco, ubicada en la región del Maule, Chile. Desarrollado con Angular, busca ofrecer una experiencia moderna, clara y accesible para la ciudadanía.
```
```
## Objetivo

El propósito de esta aplicación es mejorar la experiencia digital de los usuarios que interactúan con el sitio web municipal, facilitando el acceso a información relevante, trámites y servicios en línea.
```
```
## Tecnologías Utilizadas

- Angular 17+ (framework principal)
- TypeScript
- CSS
- Angular Router
- Responsive Design (Mobile First)
```
```
## Funcionalidades Principales

- Página de inicio moderna e informativa
- Secciones para noticias, trámites, contacto, entre otras
- Información relevante sobre la comuna de Chanco
- Diseño adaptable a dispositivos móviles
```
